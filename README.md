# Landing page — Tenis Velez Thomas

Landing page de un solo producto (tenis Velez Thomas, colores negro y miel) optimizada para móvil, con pago contraentrega.

## Archivos
- `index.html` — la landing principal.
- `gracias.html` — página de gracias + políticas de garantía (a donde llega el cliente tras enviar el formulario).
- `img/` — fotos del producto y logos de marcas.
- `video/` — video del producto (`thomas.mp4`).
- `LEEME.md` — instrucciones (píxel, compresión de fotos/video, formulario).
- `GUIA-FOTOS.md` — cómo tomar las fotos.
- `carrd-embed.html` — versión alternativa autocontenida para pegar en Carrd (no se usa en GitHub Pages).

## Publicar en GitHub Pages
1. Sube este repositorio a GitHub.
2. En el repo: **Settings → Pages**.
3. En **Source** elige **Deploy from a branch**, rama **main**, carpeta **/ (root)**.
4. Guarda. En ~1 minuto queda publicado en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Pendientes antes de lanzar
- Poner el número real de WhatsApp (busca `57XXXXXXXXXX` en `index.html` y `gracias.html`).
- Instalar el píxel de Meta o TikTok (ver `LEEME.md`).
- Conectar el formulario a WhatsApp / Google Sheets / n8n para recibir los pedidos.
- Subir el video `video/thomas.mp4` (comprimido) y más fotos por color.
